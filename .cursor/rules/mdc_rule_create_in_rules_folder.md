# MDC Rule: Rule File Organization

- All new MDC rules must be created in the ".cursor/rules" directory.
- Each MDC rule must be placed in a separate file within this directory.
- Do not combine multiple rules in a single file.
- File names should be descriptive of the rule's purpose.

This ensures clear organization and maintainability of MDC rules in the project.

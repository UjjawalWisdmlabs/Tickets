Tickets Folder
==============

Purpose:
--------
This folder contains all documentation, templates, and rules to support efficient ticket handling and client support. Use it for quick onboarding, daily reference, and to ensure no client query is missed.

How to Push Code Changes:
------------------------
1. Stage your changes:
   git add .
2. Commit with a clear message:
   git commit -m "Describe your change"
3. Push to the current branch:
   git push -u origin Tickets

How to Pull Updates:
--------------------
1. Pull the latest changes:
   git pull origin Tickets

Important:
----------
- Never miss a client query.
- Be careful and attentive when working on tickets.
- Review all changes before pushing.

Rule: Always Attach Problem Template
-----------------------------------
Every new problem/ticket must include:
- Problem description
- Steps to reproduce (if applicable)
- Impact on client
- Reference to related solution(s)

This ensures consistency and helps the team resolve issues efficiently.
